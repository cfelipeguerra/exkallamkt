# Origem das skills de SEO

As pastas desta pasta (exceto este arquivo) foram copiadas sem alterações de
https://github.com/Illyism/seo-skills (versão 1.3.0, commit 805c9c8261e60716e17efe6b834b0be7248d9ebb).

Licença MIT © Ilias Ism (https://il.ly).

Os servidores MCP do plugin original (aiseotracker, scribiz, awesome-tools) não
foram incluídos. As skills aiseotracker, scribiz, awesome-tools, ahrefs-research,
dataforseo-serp e linkdr dependem de serviços externos e, em alguns casos, de
chaves de API pagas.

Para atualizar: `npx skills add Illyism/seo-skills -a claude-code` ou copiar
novamente as pastas de seo/, content/, marketing/ e copywriting/ do repositório.
